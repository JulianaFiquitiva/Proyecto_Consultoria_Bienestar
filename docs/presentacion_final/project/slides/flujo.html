Entrega final · Índice de Bienestar Estudiantil USTA

9

Dejamos construido el flujo para que la app se actualice sola con respuestas nuevas: formulario de Google, hoja de respuestas, una tarea automática en GitHub cada hora, el mismo análisis del estudio, y la app se vuelve a publicar. Cada actualización tarda unos 22 segundos. Las respuestas nuevas se califican con los parámetros IRT del estudio, así que quedan en la misma escala y se pueden comparar. ¿Por qué no reestimar los parámetros con cada respuesta? Con pocas respuestas serían inestables y la escala cambiaría cada hora. Está lista pero no activada, porque la encuesta todavía no se aplica.
